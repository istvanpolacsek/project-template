# Architecture decision records

One short file per decision that is hard to reverse or that a newcomer would question: `NNNN-title.md`, numbered in order, never rewritten (supersede with a new record and update the old one's status).

Start from [0000-template.md](0000-template.md). Keep it under a page. A plan-mode task that makes such a decision should end with an ADR as one of its steps.
