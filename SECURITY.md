# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting: **Security > Report a vulnerability** on this repository. You will get a first answer within a few working days.

Include what you found, how to reproduce it, and the affected version or commit. Credit is given unless you prefer otherwise.

## Supported versions

Only the latest release (`main`) receives fixes.

## Dependencies

Dependabot alerts and security updates are enabled in the repository settings; `/deps` audits and fixes what they miss.
